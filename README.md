<h1>Cryptoverse</h1>

Cryptoverse is a responsive cryptocurrency-themed web project developed using the Bootstrap library. 
The project focuses on creating a modern, user-friendly, and mobile-responsive interface by utilizing Bootstrap components and layout systems.

<h2>Technologies Used and Libraries Used</h2>

HTML5 CSS3 Bootstrap
